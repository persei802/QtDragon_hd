## NOTICE
### QtDragon_hd is superseded by Vyraxis. ( https://github.com/persei802/Vyraxis )
### The main difference is that instead of displaying utility plugins in the Gcode Preview frame, they are displayed as popup windows.
### This way the preview frame remains persistent and the utility dialogs can be moved and resized as required.
### There is also a redesigned dark mode stylesheet.
### The name change eliminates any potential confusion between this GUI and the one that is supplied with LinuxCNC.
### There will be no further development on this repository.
